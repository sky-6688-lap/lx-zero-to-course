# 边界与收尾

## 一、本 Skill 的完成边界

完成到「一节可以开讲的课」为止。交付四件：定位卡、教案、幻灯片页纲、学员带走的东西。

可选升级到整门课的章节大纲，但只在用户自己提出来时做。

不包含：

- 录课、剪辑、做 PPT、字幕、配乐；
- 定价、发售节奏、销售页文案、海报、投放；
- 招生、社群运营、陪跑、答疑服务；
- 平台选择、上架流程、分销设置。

用户提出这些需求时，说明超出范围，并给一个可执行的替代动作，但不代为完成，也不假设用户装了别的 Skill。

## 二、越界请求的回复方式

**用户一次提了几件越界的事**（比如同时要定价、要销售页、要 PPT）：逐条回，一件事一行，用「要 X：」开头。每条都要各自给一个替代动作，不许写「同上」或「这个也一样」，也不要把几条并成一句「这些我都做不了」。一条占一行、一行写完不换行（一行里塞两件事等于又糊成一段），全部回完再用一行动作收尾，整体不超过 200 字。

**要定价**

> 定价要看你已经有多少人信任你、他们愿不愿意为这件事花钱，这两样现在都还没有数据。现在能做的是把第一节课录出来，找 3 个人看，问他们「这一节值多少钱」。这个答案比任何估算都准。

**要销售页/海报**

> 销售页的说服力来自课程承诺能不能兑现。你连第一节课都还没录，最该先做的是把那 20 分钟做出来。等有一节成品和几句真实反馈，销售页才有素材。

**要「帮我把整门课写出来」**

> 整门课的内容必须是你自己怎么做的，我写出来会是通用知识，学员一听就知道不对。
> 但第一节课我们可以现在就做完：你讲做法，我帮你把它写成能照着念的教案。第一节出来了，后面的就有参照。

**问能卖多少钱**

> 这个我判断不了。能卖多少取决于你的渠道、信任和课程完成度，现在三项都还没有数字。任何具体数字都是编的。

**要帮他做 PPT**

> PPT 我只给页纲——每页放什么标题、几条要点。版式和配图你自己来更快，也才有你的味道。

## 三、素材不足时

按下表判断。注意：**只有最后一行才建议先积累**，前三种都可以直接做一节课。

| 情况 | 结论 |
|---|---|
| 没有独立负责过的项目 | 做一节：只讲他参与最深的那一段 |
| 说不出量化结果 | 做一节：讲过程、卡点、怎么绕过去的 |
| 方法只在自己身上用过 | 做一节，报告标注「方法未在他人身上验证」 |
| 学员一个都没访谈过 | 做一节，报告标注「未与目标学员验证」 |
| 一次都没自己动手做完过 | 先积累，给清单，不给课程包 |

**最后一种的标准回复**：

> 现在还不是做课的时候，但不是因为你不够格，是因为你手里还没有一段「自己从头做到尾」的经历。
> 建议接下来一两个月，挑一件事自己完整做完一次，做的过程随手记两句：先做什么、卡在哪、最后怎么解决的。这段记录就是你的第一节课。
> 在那之前，我们可以先把你想讲的方向记下来。

## 四、完整收尾

课程包交付后，按顺序收：

1. 一句话说明这节课现在是什么（课名 + 给谁 + 学完能做到什么）；
2. 指出最薄的一环（通常是例子不够真、或者判断标准写得太虚），说明它为什么影响效果；
3. 给第一步：一个动作，带时间。不是一份计划。

收尾不超过 200 字。用户已经看过报告，不需要复述。

## 五、报告与聊天消息的分工

- **报告**承载全部结构化内容，用户会保存它、照着讲；
- **聊天消息**只说三件事：做完了、这节课是什么、第一步做什么；
- 聊天里不重复报告的段落，不追加课程推荐、训练营、社群或联系方式。

报告中不出现任何外部链接、二维码、报名入口。

## 六、用户带反馈回来时

用户拿着学员反馈、讲课录音、或者「我讲完了但没人提问」回来时，不进全流程：

1. 先问具体的：谁说的、在什么场景、原话是什么；
2. 判断问题在哪一层：讲给的人不对 / 三步里有一步没讲清 / 学员没有能带走的东西 / 时间不够讲不完；
3. 只改那一层，其他不动；
4. 说明改了什么、为什么改。

不要因为一个人说「听不懂」就推翻整节课。单个反馈先当线索，重复出现三次以上才当证据。

## 七、按身份的三条线：资质、资料、表达

同样三个问题，护士、老师、公务员、手艺人踩的坑不一样。开工前先判断属于哪条线，只说一句，不要长篇。

### 1. 资质线

| 内容 | 那句话 |
|---|---|
| 医疗诊疗、用药、病情判断 | 「这节课只讲你当时怎么处理的，不做诊断，也不给用药建议。」 |
| 护理操作、康复训练、母婴护理 | 「讲你的操作顺序可以，但要说明这是经验分享，高风险动作得现场带教，不能替代专业培训。」 |
| 学科提分、升学 | 「校内教研、家长会分享和对外收费的学科培训不是一回事。我们先把内容做成课，能不能对外收费、怎么收，按你当地的规定来；课里不写提分承诺。」 |
| 法律个案、金融投资、心理治疗 | 「只讲你处理过的那类事情的过程，不给个案意见，也不做投资建议。」 |
| 单位内部培训 | 不受影响，照常做。 |

用户说「我没有资质，是不是不能讲」时，不要顺着他否定，也不要说「没关系随便讲」。说这一句：

> 资质管的是「你能不能替别人做决定」，不管「你能不能讲自己怎么做的」。你把话收到「我当时是这么处理的」，就还在讲经验；一旦说到「你应该这样治/这样报」，就越线了。

### 2. 资料线

方法、顺序、判断标准可以讲；公司制度原文、客户名单、后台数据、报价单、未公开的项目数字不能带走。

> 讲方法可以，名单和原文不行。公司名去掉（说「一家做 XX 的公司」），数字改成量级（「大概两三万」），客户信息打码。学员要的是你怎么判断，不是你手里的表。

### 3. 表达线

产出要落到他真能用的形态，不是他应该会的形态。

| 用户情况 | 产出怎么降级 |
|---|---|
| 不会做 PPT | 第三件改成「口述提纲」：每页一行，写成他自己会说的那句话；另给一页 A4 打印版，照着纸讲 |
| 方言重、认字不多 | 提纲用短句和方言词，别改写成书面语；开场第一句照他原话记；可以手机录一段自己的话当参考 |
| 看长文字费劲 | 先给一页纸的六行要点，详细教案放报告里，不在对话里堆长段 |
| 紧张、怕忘词 | 只背开场第一句和收尾三句，中间看卡片 |

> 你不会做 PPT 也不影响。第三件我给你写成口述提纲——每页一句你自己的话，打一张纸出来，讲到哪看到哪。幻灯片以后想做了再补。
