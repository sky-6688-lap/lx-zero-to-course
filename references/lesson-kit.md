# 课程包：四件产出怎么写

课程包的作用是让用户**合上对话就能开工**。判断标准只有一条：他拿着它，今天能不能录出第一段。

四件按顺序产出：定位卡 → 教案 → 页纲 → 学员带走的东西。不要先写页纲，页纲是教案的结果。

## 一、定位卡（5 行）

```
课名：______（用学员的问题当课名，不要用方法名）
给谁听：______（一种人，一个阶段）
他现在的麻烦：______（具体到某个动作做不下去）
学完能做到：______（一个可以验证的动作）
这节课不解决：______（一句，防止期待错位）
```

写法要求：

- 课名优先用学员的话。「客户发火时怎么回」比「客诉情绪管理三步法」好；
- 「给谁听」只能是一种人。写「新人和老手都适合」等于没写；
- 「学完能做到」必须能验证：他能不能做出来，别人看得出来。

## 二、教案（核心件）

### 20 分钟标准时间轴

| 时间 | 段落 | 这一段要干的事 |
|---|---|---|
| 0:00–1:30 | 开场钩子 | 复现一个学员正在经历的场面，让他觉得「说的就是我」 |
| 1:30–3:00 | 承诺与边界 | 学完能做到什么、这节课不解决什么 |
| 3:00–6:00 | 讲清为什么难 | 三种常见错法，指出错在哪（先破再立） |
| 6:00–14:00 | 三步做法 | 每步 2–2.5 分钟：结论 → 怎么做 → 怎么判断做对了 → 一个反例 |
| 14:00–17:30 | 带着做一遍 | 给一个场景，让学员照着三步填，边讲边填 |
| 17:30–19:30 | 收尾 | 回顾三步、亮出卡片、留一句「什么时候别用」 |
| 19:30–20:00 | 作业 | 一个动作，明天上班就能做 |

45 分钟版：三步各给 6–8 分钟（每步加一个完整案例），练习延长到 10 分钟。
60 分钟版：在「讲清为什么难」后面加一段「什么时候这个方法不管用」，其余按 45 分钟版。

### 开场钩子：三种写法，选一种

**场景复现**（最好用）

> 「客户在群里发了一长段，最后一句是『你们就是这样对待老客户的？』——你打了三行字，删了，又打三行，又删了。」

**反问**

> 「你有没有过这种时候：明明按流程回了，客户反而更生气？」

**对比**

> 「同样一句话，一个人说完客户说谢谢，另一个人说完客户直接投诉。差别不在态度，在顺序。」

开场只做一件事：让他想起自己那个场面。不要在这段做自我介绍，不要讲课程由来。

### 承诺与边界

固定句式：

> 「这 20 分钟只讲一件事：____。学完你能 ____。我不讲 ____，那是另一件事。」

### 讲清为什么难（三种错法）

每一条写三行：错法是什么 → 为什么会这么做 → 结果是什么。

例：

> 一上来就解释规定——因为你怕担责任，想先把自己摘出去——客户听到的是「你在推」。
> 一直道歉不给方案——因为你想先稳住他——他听到的是「你在拖」。
> 直接答应赔——因为你想快点结束——下次他会用同样的方式再来一次。

这一段的作用不是骂人，是让学员承认「我这么干过」。承认了才愿意听后面的。

### 三步做法：每步四句话

```
第 N 步：【动词开头的短句】
一句话结论：这一步只干一件事——____。
怎么做：先 ____，再 ____，然后 ____。
怎么判断做对了：如果 ____，说明这步成了；如果 ____，退回上一步。
反例：____ 这样做，看起来对，其实会 ____。
```

四句话缺一句，这步就没讲完。尤其「怎么判断做对了」——没有它，学员听完还是不知道自己做对没做对。

### 带着做一遍

给一个和学员处境接近的场景，让他用三步填空。口令固定：

> 「现在换个场景：____。你先做什么？停三秒想一下，再往下听。」

然后给参考答案，并且说明「你的答案可能和我不一样，只要满足这个判断标准就行」。

### 收尾

三件事，按顺序：

1. 三步复述一遍，每步一句，不展开；
2. 亮出卡片（第四件产出），说「这张你截个图，明天用」；
3. 给一句边界：「这套只在 ____ 的情况下好用，遇到 ____ 就别硬套。」

### 作业

一个动作，一句话，带时间和对象：

> 「明天上班，遇到第一个发火的客户，先用第 1 步判断他要什么，再回。回完把那段对话截下来，自己对照一次三步。」

不要布置「写一篇复盘」「总结你的心得」这类作业，没人做。

## 三、幻灯片页纲（10–12 页）

| 页 | 内容 | 备注 |
|---|---|---|
| 1 | 课名 + 一句承诺 | 课名照定位卡，不要加副标题 |
| 2 | 三个场景（学员的日常） | 每行一句，都是他能对上号的事 |
| 3 | 学完你能 / 我不讲 | 两栏，各三条以内 |
| 4 | 大多数人会犯的三个错 | 只写错法，不写答案 |
| 5 | 我的做法：三步 | 全课唯一的总览页，三步只写动词 |
| 6 | 第一步 | 结论 + 怎么做（三小条） |
| 7 | 第一步的例子 | 真实对话或截图，不要示意 |
| 8 | 第二步 | 同第 6 页结构 |
| 9 | 第二步的例子 | |
| 10 | 第三步 | |
| 11 | 三步卡（截屏页） | 一页放下三步 + 判断标准 |
| 12 | 作业 + 什么时候别用 | 收尾 |

20 分钟的课不要超过 12 页。三步如果各配一个例子，可以省掉第 2 页。

## 四、学员带走的东西

三种形态，按用户的做法选一种，不要都做：

**A. 三步卡**（最通用）

```
【课名】三步卡
① ____ ｜ 做对了是：____ ｜ 常见错：____
② ____ ｜ 做对了是：____ ｜ 常见错：____
③ ____ ｜ 做对了是：____ ｜ 常见错：____
什么时候别用：____
```

**B. 话术表**（涉及和人打交道的课）

```
场景 ｜ 别说这句 ｜ 改说这句 ｜ 为什么
```

**C. 自检清单**（涉及交付物质量的课）

```
开工前检查：____
做完检查：____
交付前检查：____
```

判断标准：把这张纸单独发给一个没听过课的人，他能不能照着用。不能，就说明写得太抽象，把「注意沟通」改成「先说『换我我也急』，再说处理方案」。

## 五、示例产出（接 beginner-path.md 里的客服案例）

**定位卡**

- 课名：客户发火的时候，第一句怎么回
- 给谁听：做客服半年以内、还没独立处理过投诉的新人
- 他现在的麻烦：一看到客户发火就慌，要么解释规定，要么一直道歉，越回越僵
- 学完能做到：接到一条发火的投诉，先判断对方要什么，再按三步回完，不激化
- 这节课不解决：不教赔偿标准怎么定，也不教怎么跟平台申诉

**教案片段（第二步）**

> 第 2 步：先接住情绪，再给结论。
> 这一步只干一件事——让他觉得你听懂了。
> 怎么做：先说一句「换我我也急」，再说「我这边现在能做的是……」，最后说时间。
> 怎么判断做对了：如果对方从「你们」变成「你」，说明接住了；如果他还是连发三条，说明第一句说得像套话，换一句更具体的。
> 反例：「非常理解您的心情，但是……」——「但是」之前的所有话，他都不会听。

**页纲**：12 页，第 11 页是「客服回话三步卡」。

**带走的东西**：话术表，四列：客户说的原话 / 别回这句 / 改回这句 / 为什么。

## 六、四种不合格的课程包

| 症状 | 原因 | 怎么改 |
|---|---|---|
| 教案里全是「要讲清楚 XX」 | 没落到具体说法 | 每句改成可以直接念的原话 |
| 页纲 30 页 | 把整门课塞进一节 | 砍到 12 页，删掉「背景介绍」「行业趋势」 |
| 学员带走的东西是一句口号 | 没有可操作内容 | 改成填空表，每格都要能填具体的话 |
| 例子是编的 | 没问用户真实经历 | 回到第 2 问，把那次的原话要出来 |
