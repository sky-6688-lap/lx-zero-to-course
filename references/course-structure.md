# 阶段三：确定课程结构

课程结构就是大纲，是一节课一节课的骨架。这一步最容易出问题的地方不是不会排章节，而是**知识诅咒**：自己知道了，就想象不出别人不知道。

## 一、从经验到交付物，要走三步转换

讲师的经历不能直接变成课程，中间必须换三次形态：

| 形态 | 是什么 | 学员拿到后 |
|---|---|---|
| 方法论 | 从工作经历中抽象出的、可反复用于解决问题的一套完整方法 | 知道该怎么做 |
| 知识点 | 方法论拆开后的具体要点，与工作场景绑定 | 知道每一步在解决什么 |
| 交付物 | 具体工具、模板、判断模型、清单 | 手里多了能直接用的东西 |

三者缺一，课程就会变形：

- 只有方法论没有交付物 → 学员觉得「有道理但用不上」；
- 只有交付物没有方法论 → 学员照抄但换个场景就崩；
- 知识点不绑定场景 → 学员记不住。

## 二、萃取方法论：四步走完流程

从用户口述的经历里提炼，不要直接让他「总结一下方法论」——多数人总结不出来。

### 第 1 步 横向拉出流程

> 这件事从头到尾分几步？你实际做的顺序是什么？

把步骤写下来。重点打磨两类步骤：

- **关键步骤**：直接决定最终交付物质量的，不做不行的那几步；
- **约定俗成的步骤**：行业里大家都知道、展开讲两句就够的，不要占篇幅。

### 第 2 步 纵向挖每步的困难

> 这一步最容易出什么错？新人在这儿通常卡在哪？

这一步挖出来的就是知识点。学员的困难点，才是需要讲的地方；讲师做得顺的地方，反而常常不需要讲。

### 第 3 步 定每步的产出

> 这一步做完，手里应该多出什么东西？

产出就是交付物的雏形。如果某一步说不出产出，这一步大概率可以合并到前后步骤里。

### 第 4 步 回检覆盖

> 拿着你的流程，能不能回答学员最常问的那几个问题？

答不上的问题，说明流程有缺口，回去补步骤。

## 三、把知识点做成可交付的工具

职业类课程的学员要的是**拿来即用**：先照着做拿到结果，再慢慢变成自己的经验。

拿「让新人筹办一场线下品牌活动，负责邀请嘉宾」举例。只说「要请有吸引力的嘉宾」是没用的，要针对他实际会卡住的问题给出工具：

| 学员的问题 | 该给的交付物 |
|---|---|
| 这是什么发布会，适合请什么样的嘉宾 | 匹配判断工具（发布会类型 × 嘉宾类型） |
| 预算不够，怎么请到人 | 说服话术 + 成功案例 |
| 怎么运营嘉宾，让效果超预期 | 嘉宾运营 SOP |
| 嘉宾临时改时间怎么办 | 突发应变补救方案 |
| 合作之后怎么长期维护 | 嘉宾库模板 + 日常维护方案 |

**交付物清单常见形态**：判断清单、自检清单、对比表、SOP、话术模板、报价/预算表、复盘表、学习地图。

知识小课 1–3 个交付物；体系课程每章 1–3 个。

## 四、选一种结构

| 结构 | 适用条件 | 举例 |
|---|---|---|
| 流程串联式 | 知识点之间有上下游关系，先会 A 才能理解 B | 新媒体写作课 |
| 模块并列式 | 知识点相对独立，可以任意顺序学 | 运营能力课：活动、文案、投放各成一章 |
| 循序渐进式 | 同一套方法从易到难用在不同场景 | 策略产品经理：先讲思考方法，再套进各类业务 |

不要混用。一门课里既有并列模块又有递进主线，学员会不知道自己在哪。

## 五、知识小课的结构

### 标准结构：总—分—总

```
提出概念（为什么这事值得学）
   ↓
展开详解（3–5 个模块）
   ↓
延伸总结（回顾 + 更多应用场景 + 注意事项）
```

### 1 小时的配比

| 部分 | 时长 | 内容 |
|---|---|---|
| 引言 | 5 分钟 | 课程背景、个人介绍、学员能带走什么 |
| 提概念 | 5 分钟 | 是什么、为什么重要、和别的做法有什么不同 |
| 展开详解 | 40 分钟 | 3–5 个模块，每模块 8–13 分钟 |
| 延伸总结 | 10 分钟 | 回顾核心步骤、给更多案例、提醒注意事项 |

### 按小课类型调整开头

**工作方法类**——开头要做四件事之一：正面案例与反面案例对比、用岗位要求和薪酬给未来憧憬、呈现真实冲突、指出一个常见错误认知及其后果。中间讲方法时区分两种情况：自创方法重点讲操作步骤和每步结果；引自经典的方法重点讲已经用在哪些工作里、比别的方法好在哪。结尾带学员回顾核心步骤，给案例练手，再点几个注意事项。

**工具实操类**——开头先展示用这个工具做出来的成品，绝对不要一上来就讲功能。中间给操作步骤 + 关键提示。结尾再整体看一遍成品，强调亮点与关键步骤，给继续精进的路径和资源。

**新知新见类**——重点在讲清概念的生命周期与适用边界，别把课做成新闻播报。

## 六、体系课程的结构

### 章节规格（以 5 小时课程为例）

- 5–10 章，每章 3–5 节；
- 每节约 15 分钟视频 + 配套材料；
- 部分章节配测试、作业或在线实操。

### 排章节的顺序

1. 先筛出与教学目标直接相关的核心知识点，**不要先想章节标题**；
2. 判断知识点之间是上下游、并列还是递进，决定结构类型；
3. 按结构把知识点装进章，再给章起名字；
4. 用「能不能解决学员真实问题」「是否匹配真实工作场景」两条砍掉多余内容。

### 大纲模板

```
第 1 章 【章名】                     总时长 __ 分钟
  1.1 【节名】 __ 分钟   交付物：______
  1.2 【节名】 __ 分钟   交付物：______
  1.3 【节名】 __ 分钟   交付物：______
  本章要解决的问题：______
第 2 章 ……
```

每一节都要填交付物。填不出来的节，说明还没设计完，先别写进大纲。

## 七、找差异化：四个方向

课程做出来一定会遇到「市面上已经有了」。差异化不必是全新内容，可以从四个地方找：

| 方向 | 做法 |
|---|---|
| 人群差异 | 按工作年限、行业、公司规模切分，服务被忽略的那一段 |
| 内容差异 | 市面资料零散 → 你做体系化；竞品已全面 → 你切一个垂直点做深 |
| 目标差异 | 竞品停在「深刻理解」→ 你加练习和反馈做到「熟练掌握」 |
| 结构差异 | 大量与知识点绑定的稀缺案例，或更贴合当下学员的学习设计 |

判断维度只有两个：**未被满足的需求**，和**主题/形式相近的直接竞品**。
