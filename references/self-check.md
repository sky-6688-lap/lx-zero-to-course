# 交付前自检

课程包交付前跑一遍。任何一条打不了勾，都要在报告「开讲前待补」里写明，不要隐瞒。

## 一、一节课必过（七条）

**定位**
- [ ] 课名用的是学员的问题，不是方法名
- [ ] 「给谁听」只写了一种人、一个阶段
- [ ] 「学完能做到」是一个看得见的动作，不是「有所提升」
- [ ] 能说出这节课**不解决**什么

**教案**
- [ ] 开场第一句是原话，带引号，能直接念
- [ ] 开场第一句念出来不超过 15 秒（约 60 字）；超了就砍到一句半，不要靠加快语速
- [ ] 三步都写全了四句：干什么 / 怎么做 / 怎么判断做对了 / 常见错
- [ ] 三步每步的「怎么做」里都有一句带引号的原话，不是「要共情」这类描述
- [ ] 三步里至少有一步用了用户自己的原话或真实场景
- [ ] 有一处「什么时候这个方法不管用」
- [ ] 写了三个可能被问到的提问，其中一个是「这招不管用怎么办」；答不上来时的说法也写好了

**学员侧**
- [ ] 学员带走的东西，单独拿出来也能照着用
- [ ] 另有一份纯文本版，用户能直接粘到微信、备忘录或文档里
- [ ] 结尾有一个明天就能做的动作，带时间
- [ ] 页纲页数与本次时长匹配（10 分钟 8 页 / 20 分钟 ≤12 页 / 45 分钟 14–16 页 / 60 分钟 16–18 页），每页不超过 3 行、每行不超过 15 字

## 二、按身份的三条线（涉及才勾）

- [ ] **资质**：内容涉及医疗、护理、康复、法律、金融、学科提分、心理治疗时，说过那句边界话术；报告里留了「不替代专业培训与医嘱／不构成个案意见」
- [ ] **资料**：公司名去掉了，数字改成量级，客户信息打了码，制度原文没有整段搬
- [ ] **表达**：不会做 PPT / 方言重 / 看长文字费劲的人，拿到的是口述提纲或打印一页纸，不是一份他做不出来的页纲

三条都不涉及就跳过本节。

## 三、课程包四件是否齐

- [ ] 定位卡（五行）
- [ ] 教案（时间轴 + 开场 + 三步 + 练习 + 收尾）
- [ ] 页纲（每页标题 + 内容，页数按 SKILL 的时长表：10 分钟 8 页 / 20 分钟 10–12 页 / 45 分钟 14–16 页 / 60 分钟 16–18 页）
- [ ] 学员带走的东西（卡 / 表 / 清单，内容已填好）

少一件就是没做完，不要说「后续可以补」。

## 四、做整门课时加测

先分清规模，再对照检查项：

| 规模 | 规格 | 每节时长 |
|---|---|---|
| 小系列（默认的升级结果） | 5–8 节 | 15–20 分钟 |
| 体系课程（用户明确要做 5 小时以上） | 5–10 章，每章 3–5 节 | 约 15 分钟 |

- [ ] 节数/章数落在上表对应的那一档，没有把 5 节的系列按章节规格去凑，也没有把体系课压成 8 节
- [ ] 每节都能说出一句话的主线，串起来是一门课
- [ ] 两个最难的节没有连在一起
- [ ] 第一节是全课最容易上手的，不是最难的
- [ ] 每节都套用了同一份教案模板，没有中途换写法

## 五、五种不合格

| 症状 | 原因 | 怎么改 |
|---|---|---|
| 教案里全是「要讲清楚 XX」 | 没落到具体说法 | 每句改成能直接念的原话 |
| 页纲 30 页 | 把整门课塞进一节 | 砍回本次时长的上限页数，删「背景」「趋势」 |
| 学员带走的东西是句口号 | 没有可操作内容 | 改成填空表，每格能填具体的话 |
| 例子是编的 | 没问真实经历 | 回到第 2 问，要那一次的原话 |
| 讲的人是他自己，不是学员 | 站在讲师立场 | 把每句主语换成「你会遇到」，重写 |

## 六、报告里的呈现

- 通过的项不逐条列出，避免报告变成打勾表；
- 未通过的项必须出现在「开讲前待补」，写清缺什么、怎么补、大概多久；
- 没跟真实学员验证过的，在报告开头就标注「尚未与目标学员验证」，不要放最后一行。
