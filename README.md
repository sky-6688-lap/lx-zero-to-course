# 零基础做课 Skill

一个陪零基础的人把「我会的那点事」变成「一节能开讲的课」的 Skill。

它不教你课程设计理论，也不要求你先写出大纲。**你只需要回答三个问题，它给你一节课的全部材料。**

用完这一次，你手里不是一份计划，是这些东西：

| 你会拿到 | 具体是什么 |
|---|---|
| 定位卡 | 课名、讲给谁、他现在的麻烦、学完能做到什么、这节课不解决什么 |
| 教案 | 20 分钟分段时间轴、开场第一句原话、中间三步怎么讲（每步一句能照念的原话）、带着学员做一遍、收尾，以及学员最可能问的三个问题和怎么答 |
| 幻灯片页纲 | 按时长定页数：10 分钟 8 页 / 20 分钟 10–12 页 / 45 分钟 14–16 页 / 60 分钟 16–18 页；每页标题和要点（每页不超过 3 行），打开 PPT 就能填 |
| 学员带走的东西 | 一张三步卡 / 话术表 / 自检清单，内容已经填好；另附一份能直接粘到微信里的纯文本 |
| 第一步 | 今天就能做的一个动作 |

默认 20 分钟，也可以说 10 分钟（线上短分享）、45 分钟或 60 分钟——页纲和每步时长会跟着变，结构不变。第一次讲没底，先要 **10 分钟版**。

## 它问的三个问题

不是「你擅长什么」，那个问题没人答得出来。是这三个：

1. **最近半年，有谁问过你一个工作上的问题？** 他是谁，问的什么，原话大概是什么。
2. **那次你是怎么处理的？** 不用总结，按你实际动手的顺序说。
3. **如果他自己做，最容易在哪一步做错？** 错了会怎样。

三个答完就够了。说「我不知道我能讲什么」也行，它会往下给提示——带过新人吗、有没有人找你要过一份表格、你被夸过什么、你每天重复做的那件事是什么。

## 为什么这样设计

**先做一节，不做一门。** 大多数人做课死在第一步：一上手就想做一门系统课，写到大纲第三章就停了。一节课 20 分钟，一两天就能做完，做完你就知道自己行不行。

**被问过，就算需求被验证过。** 不需要你是专家，不需要有漂亮的数据。有人来问过你、你真上手做过一次，就够一节课的量。

**产出必须能照着念。** 教案里不放「要讲清楚 XX」这种话，放的是开场第一句的原话、每一步的具体说法、判断做对没做对的标准。你打开它就能录。

## 怎么用

**第一步，安装。**

> 帮我安装这个 skill：https://github.com/sky-6688-lap/lx-zero-to-course

更新到最新版：

> 请把我已经安装的这个 skill 更新到最新版，覆盖旧版本：https://github.com/sky-6688-lap/lx-zero-to-course

**第二步，说一句。**

> 使用 $lx-zero-to-course，帮我把我会的一件事做成一节课。

带背景也行：

> 我做了 4 年电商客服，现在带一个小团队。想做个课，但不知道从哪切。请用 $lx-zero-to-course 帮我。

**第三步，回答三个问题。**

不用准备材料，想到哪说到哪，说错了它会帮你收。全程 15 分钟左右。

想做成好几节，做完第一节再跟它说：

> 这节课我想扩成 5 节，帮我排一下。

## 适合谁

- 从没做过课，但工作里被人反复请教过的人；
- 觉得自己「很普通、没什么可讲」的人（这类人往往最有的讲，只是不会往外掏）；
- 写过大纲、但一讲就像念笔记的人；
- 已经讲过一次、但没人提问或讲到一半卡住的人——它会先帮你诊断卡在哪一层，只改那一层，不推倒重来。

不太适合：一次都没有自己动手做完过一件事的人。这种情况它会给你一份积累清单，而不是一节课。

## 它不做什么

不代写整门课的全部内容（第一节可以陪你写，因为要用你的原话）；不做定价、发售、销售页、海报、招生；不承诺销量和收入。
